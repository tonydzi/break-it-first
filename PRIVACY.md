# Privacy policy: break-it-first

Last updated: 16 November 2026.

This repository and its Claude Code plugin are instructions only (Markdown and JSON).
They collect no data, send no data anywhere, run no code and start no server.

Any commands the agent runs while following the skill run in your own environment under your
agent's settings. If you choose to use the adversarial review step with other model vendors,
what you send to them is governed by those vendors' policies.
